⚙️ How to Use in Your Project

Option 1: Default (Recommended)

<script src="instantpage.js" type="module"></script>

Option 2: Conservative (Mousedown)

<body data-instant-intensity="mousedown">
  <!-- Your content -->
  <script src="instantpage.js" type="module"></script>
</body>

Option 3: Aggressive (Viewport - Mobile)

  <!-- Your content -->

🎛️ Configuration Options

Data Attribute Purpose
data-instant-intensity Hover delay (ms), "mousedown", "viewport", etc.
data-instant-whitelist Only prefetch links with data-instant
data-instant-allow-query-string Enable prefetch for URLs with query params
data-instant-allow-external-links Enable cross-origin prefetch (Chromium only)
