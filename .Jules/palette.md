## 2024-05-22 - Accessibility Fundamentals in Test Clients
**Learning:** Even internal test clients benefit significantly from basic accessibility standards. Adding `:focus-visible` and proper cursor styles made the test interface much more usable for keyboard verification without any functional overhead.
**Action:** Always check internal tools for basic keyboard accessibility (focus rings) and cursor affordance, as it improves developer experience and serves as a testing ground for a11y patterns.
